# Деталь — поиск автозапчастей

**React + Redux Toolkit / RTK Query + Bootstrap**, обычный JavaScript, без
TypeScript и прикладного сервера. Все HTTP-запросы выполняются из браузера
через `fetchBaseQuery`. Демоответов в приложении нет.

## Запуск

Node.js **22.12+**.

```powershell
npm.cmd install
Copy-Item .env.example .env
```

Заполните `.env`:

```dotenv
VITE_FAVORIT_API_KEY=ваш-ключ
```

```powershell
npm.cmd run dev
```

Откройте http://127.0.0.1:5173. После изменения `.env` перезапустите Vite.
На Windows `npm.cmd` не зависит от политики запуска PowerShell-скриптов.
На других системах используйте `npm`.

**Важно при переходе со старой версии:** вместо серверной переменной
`FAVORIT_API_KEY` теперь нужна `VITE_FAVORIT_API_KEY`. `PORT` больше не
используется. Остановите старый Express-процесс перед запуском предпросмотра.

## Ограничения прямого подключения

- **Ключ не является секретным:** `VITE_` подставляется в клиентскую сборку.
  Ключ доступен пользователю в JS и сетевых запросах. `.gitignore` защищает
  `.env` от коммита, но не скрывает ключ в опубликованном приложении.
  Не размещайте приложение публично с ключом, который нельзя раскрывать.
  Если ключ нужно скрыть, необходим сервер-посредник.
- **CORS должен разрешаться сервисом Фаворит** для origin приложения.
  RTK Query не обходит CORS; Vite proxy и `no-cors` не используются.
  При блокировке запросов потребуется настройка CORS у поставщика либо
  возврат к серверу-посреднику. Браузер не позволяет надёжно отличить CORS
  от сетевого сбоя — интерфейс указывает обе возможные причины.
- Используется только HTTPS, без автоматического перехода на HTTP.
  Прямой запрос из браузера на `http://127.0.0.1:3001` без ключа вернул
  читаемый HTTP 403 (тип ответа `cors`), а заголовок сервиса —
  `Access-Control-Allow-Origin: *`. CORS для этого ответа не блокировался.
  Это не подтверждает
  работоспособность API с вашим ключом и origin. Проверьте реальный поиск
  после настройки ключа.

## Сборка и проверки

```powershell
npm.cmd test
npm.cmd run lint
npm.cmd run build
npm.cmd start
```

Предпросмотр сборки: http://127.0.0.1:3001.
`npm start` — статический Vite preview, а не API-сервер. Для production
разместите содержимое `dist` на статическом HTTPS-хостинге.
Ключ подставляется **при сборке**: при его смене пересоберите приложение.
Наличие Node.js на статическом production-хостинге не требуется.

## Поиск и данные

Документация: https://lk.favorit-parts.ru/static/wsprice.pdf (06.03.2023).
Адрес: `https://api.favorit-parts.ru/hs/hsprice/`.

- `getBrands(number)`: `key`, `number`. Бренды извлекаются из `goods`,
  удаляются дубликаты без учёта регистра.
- `getOffers({ number, brand })`: дополнительно `brand`, `analogues=on`.
  Исходные товары и вложенные `analogues` разворачиваются в предложения.
- Одна строка — один склад: цена из `warehouses[].price`, остаток из
  `warehouses[].stock`. Устаревший `goods.price` не используется.
  Если складов нет, показываются общий `count` и отсутствие цены.
- Пустые `goods` и пустая структура внутри `goods` означают отсутствие
  результатов. Нулевые остатки отображаются явно.
- Поиск запускается через 500 мс после ввода либо по Enter / кнопке.
  При смене артикула очищаются выбор и выдача; запросы отменяются.
  RTK Query разделяет кеш по аргументам; интерфейс использует `currentData`,
  чтобы запоздавшие ответы не отображались для другого артикула / бренда.
- Кеш неиспользуемого запроса хранится 60 секунд. Автопоиск может использовать
  кеш, кнопка поиска и выбор бренда запрашивают свежие данные.
- Состояния загрузки, ошибок, повтор запросов и кеш обслуживает RTK Query.
  Обрабатываются ошибки ключа, квоты, HTTP, сети / CORS, JSON и структуры
  ответа. Тайм-аут — 20 секунд. Автоматических повторов нет.
- Индикатор «Ключ API задан» означает только наличие значения в сборке,
  а не действительность ключа или доступность внешнего сервиса.
- Сохранены фильтр наличия, сортировки и мобильная прокрутка таблицы.

## Структура

```text
src/data/api.js     RTK Query API, HTTP, ошибки, сгенерированные React-хуки
src/data/parts.js   Проверка ответа и преобразование товаров
src/store/         Redux store, middleware RTK Query и состояние выбора
src/components/    Таблица, загрузка, ошибки и пустые состояния
src/App.jsx        Двухэтапный поиск
```

Тесты используют изолированные HTTP-ответы, не обращаются к Фаворит
и не требуют настоящего ключа.
